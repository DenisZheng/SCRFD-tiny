# 数据集来源与校验

本文件记录 SCRFD-tiny 训练所需数据的**来源、下载地址与实际校验值**。
数据集本身不入库（见 `.gitignore`），此文件确保可从零重建。

---

## 1. 需要两份数据

| 数据 | 用途 | 是否入库 |
| --- | --- | --- |
| **RetinaFace 5 点标注包** `retinaface_gt_v1.1` | 训练/验证的标注（框 + 5 点关键点） | 否（约 18 MB，已 `.gitignore`） |
| **WIDER Face 图像** `WIDER_train` / `WIDER_val` | 原始图片 | 否（约 1.8 GB） |

两者**缺一不可**：标注包只有 `.txt`，没有图片；WIDER 官方包只有图片（和纯框标注），没有关键点。

## 4. 目录摆放

下载解压后摆成如下结构，再运行 `tools/build_from_gt.py`：

```
retinaface_gt_v1.1/          # 标注包解压后
  train/label.txt
  val/label.txt
  test/label.txt

wider/                       # WIDER 图像解压后
  train/images/<event>/<image>.jpg      # 注意：WIDER_train.zip 解压后是 WIDER_train/images/
  val/images/<event>/<image>.jpg
```

> `build_from_gt.py` 的 `--images-root` 期望该目录下有 `<split>/images/`，
> 因此若解压得到的是 `WIDER_train/images/...`，需把 `WIDER_train` 重命名为 `train`，
> 或直接指向上层目录并确保子目录名为 `train` / `val`。
>
> 实测三张 zip 解压后的实际顶层目录名就是 `WIDER_train/images/<event>/`，
> 所以最简单的做法是：
>
> ```bash
> mkdir -p wider && cd wider
> unzip /path/WIDER_train.zip     # 得 WIDER_train/images/...
> unzip /path/WIDER_val.zip       # 得 WIDER_val/images/...
> mv WIDER_train train && mv WIDER_val val
> ```

构建命令：

```bash
python3 tools/build_from_gt.py \
  --gt-root ./retinaface_gt_v1.1 \
  --images-root ./wider \
  --out ./WIDERFace \
  --splits train val \
  --mode hardlink
```

`--mode hardlink` 用硬链接，不额外占用磁盘（转换后约 1.9 GB 是原图大小，不是副本）。

## 5. 预期结果（用于核对转换是否正确）

```
train: images=12876  faces=159393  full5=76006 (47.7%)  no_kpt=83387 (52.3%)
val:   images=3226   faces=39697    full5=0             no_kpt=39697 (100%)
```

对不上说明数据版本或转换有问题，先停下来查，不要带病训练。

### 常见偏差

| 现象 | 原因 |
| --- | --- |
| `faces` 少几十个 | 标注包里有 `w=0` 或 `h=0` 的占位无效框，会被丢弃（实测 train 31 个、val 11 个），属正常 |
| `images` 少几张 | 整图只含无效框的图，图片仍保留但标注为空；空标注图在训练时被 `Dataset` 跳过 |
| `full5` 比例约 13% | 说明把标注的 `flag` 列当成了关键点权重。正确判据是三元组 `(x,y,flag)` **全为 -1** 才算缺失，见 Docker 手册 19.3.2 |

## 6. 许可与使用边界

- **WIDER Face**：官网标注 `CC BY-NC-ND`。仅限非商业研究与演示；商业训练、对外再分发
  及许可意义上的衍生使用需另行获得授权。
- **retinaface_gt_v1.1**：随 RetinaFace 项目（MIT）发布，但其内容是基于 WIDER Face 的
  再标注，**原图仍受 WIDER Face 许可约束**。
- 因此本仓库**不收录任何图片或标注数据**，只提供来源、校验值和构建脚本。

详见根目录 `face-data-research/一手来源核查记录.md`。
